# 🎭 act-unreal

[![Unreal Engine](https://img.shields.io/badge/Unreal%20Engine-0E1128?style=flat&logo=unrealengine&logoColor=white)](https://www.unrealengine.com)
![Status: Alpha](https://img.shields.io/badge/status-0.2.0--alpha-orange)
![License](https://img.shields.io/github/license/ManasMakde/act-unreal?style=flat&color=yellow)

This is the unreal engine implementation of the **Act Pattern**.  
For a complete explaination & implementation in other game engines visit the [main repository][MainRepo].


> ## 🚧 Work in Progress 🚧
> This repo is still under construction i.e. the demo game & test cases are yet to be added.  
> However, the core codebase has been completed so feel free to use at your own discretion.


## 🛠️ Installation
If you want to use the act pattern in your project install the desired version from the [releases page][Releases] & drop the files anywhere in your `Source/` folder.  

> **Note**:  
> If you just want to view the code, Look into these 4 files:  
> 1. [`Act.h`](Demo/Source/ActDemo/ActPattern/Act.h)  
> 1. [`Act.cpp`](Demo/Source/ActDemo/ActPattern/Act.cpp)
> 1. [`Theater.h`](Demo/Source/ActDemo/ActPattern/Theater.h)  
> 1. [`Theater.cpp`](Demo/Source/ActDemo/ActPattern/Theater.cpp)
>
> _Feel free to leave a ⭐ if you use this in your project!_  


## 🧭 Usage  
Look into the README of the [main repo][MainRepo] for the principle.
